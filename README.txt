OKUHLE PETROLHEADS PROJECT

Folder structure:
okuhle_petrolheads_project/
  index.html
  css/
    style.css
  js/
    script.js

HOW TO RUN:
1. Extract the ZIP file.
2. Open the folder in Visual Studio Code.
3. Open index.html with Live Server, or open it in a browser.
4. Internet access is required for the remote car photographs.

IMPORTANT:
- The catalogue currently contains 12 example vehicle entries.
- Remote photos are illustrative automotive images and are not guaranteed to depict the exact model.
- Confirm exact South African model availability and specifications with the manufacturer.
- To add a car, add another object to the cars array in js/script.js.
